# Security policy

## Supported versions

Security fixes are provided for the **latest release** only. Please update before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Instead, use GitHub's private reporting:
**Security → Report a vulnerability** on <https://github.com/terysetn02-source/psystat>
(or contact the maintainer through the e-mail address on the GitHub profile).

Include what you found, how to reproduce it, the PsyStat version and your operating system. You can expect an
acknowledgement within about 7 days. Please give the maintainer reasonable time to fix the problem before disclosing it.

## What PsyStat does and does not do with your data

* PsyStat runs **entirely on your computer**. It does not upload data and does not need an internet connection.
* While you work, it writes **autosave copies** of your dataset to a private folder in the operating system's temporary
  directory (see the manual, Chapter 24). On shared computers, discard the recovery offer and delete your files when finished.
* Datasets you open may be CSV, Excel or SPSS files. As with any software, open files only from sources you trust.

## Privacy reminders for issue reports

Never attach real participant data to a public issue. Use the simulated example datasets or a small, fully anonymised file.
