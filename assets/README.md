# assets

* `icon.png` – your application icon (square, 1024 x 1024 recommended). **Keep your existing icon files here** (and credit the
  icon's author in the README if the icon's licence requires it).
* `icon.ico` / `icon.icns` – generated from `icon.png` with `python tools/make_icons.py`; used for the Windows and macOS builds.
* `screenshots/` – images used in the README.
