# PsyStat Example Datasets Guide

PsyStat comes with four example datasets so that you can learn every module without needing your own data. Open them from **File → Load Sample Data**. This guide describes each dataset, every variable, the effects that were built into the data, and the results you should obtain (an *answer key*), so that you can check that you are using PsyStat correctly.

> **All data are simulated.** They were generated by a computer program (`tools/generate_examples.py`, with fixed random seeds) to resemble typical psychology data. No real participants are represented, and the data **must not be used to draw substantive conclusions** about intergroup contact or any other topic. The files can be regenerated exactly by running that script.

| File | Rows | Variables | Use it to practise |
|---|---|---|---|
| `experiment_example.csv` | 300 | 18 | Descriptives, *t*-tests, ANOVA/ANCOVA, repeated measures, regression, mediation, moderation, correlation, latent profiles, growth curves, missing data |
| `survey_example.csv` | 250 | 19 | Reverse scoring, reliability, EFA, CFA, SEM, network analysis, CATPCA, Bayesian correlation, missing data |
| `cvi_expert_ratings_example.csv` | 12 | 7 | Content Validity Index |
| `timeseries_example.csv` | 60 | 2 | Forecasting |

## 1. `experiment_example.csv` — Intergroup Contact Study (N = 300)

### 1.1 The story

A (fictional) field experiment tests whether a structured, cooperative contact session between members of two groups reduces prejudice. Participants were **randomly assigned** to a **Contact** or **Control** condition (150 each). They completed questionnaires before the session (*pre*), directly after (*post*), and some weeks later (*follow-up*, prejudice only).

### 1.2 Variables

| Variable | Type | Values | Meaning |
|---|---|---|---|
| `participant_id` | ID | 1–300 | Participant number (do not analyse) |
| `condition` | Nominal (text) | Contact, Control | Experimental condition |
| `condition_code` | Numeric (dummy) | 1 = Contact, 0 = Control | Same variable, coded 0/1 for regression and **mediation** |
| `gender` | Nominal (text) | Female (~56%), Male (~41%), Non-binary (~3%) | Self-reported gender |
| `age` | Numeric | 18–35 | Age in years |
| `prejudice_pre` / `_post` / `_followup` | Numeric 1–7 | higher = more prejudice | Prejudice at three time points |
| `contact_quality_pre` / `_post` | Numeric 1–7 | higher = better contact experiences | Perceived quality of contact with the other group |
| `group_identification_pre` / `_post` | Numeric 1–7 | higher = stronger identification | Identification with one's own group |
| `intergroup_anxiety_pre` / `_post` | Numeric 1–7 | higher = more anxiety | Anxiety anticipated in intergroup encounters |
| `cooperation_pre` / `_post` | Numeric 0–100 | higher = more cooperation | Points shared in a cooperation task |
| `life_satisfaction_pre` / `_post` | Numeric 1–7 | higher = more satisfied | General life satisfaction |

### 1.3 Missing data

About 2% of the post-test values of `contact_quality_post`, `intergroup_anxiety_post`, `cooperation_post` and `life_satisfaction_post` are missing completely at random, and about 8% of `prejudice_followup` (attrition). The demographic variables and the pre-test variables are complete. Practise comparing **listwise deletion** with **FIML** (CFA/SEM) and look at how *N* changes between analyses.

### 1.4 Built-in effects and answer key

| Tutorial | Analysis | What you should find |
|---|---|---|
| A1 | Descriptives | `prejudice_pre` M ≈ 4.0; `prejudice_post` M ≈ 4.0; `contact_quality_post` M ≈ 4.5 |
| A2 | Independent *t*-test: `contact_quality_post` by `condition` | Contact M = 5.06 (SD 0.84, *n* = 147), Control M = 3.93 (SD 0.95, *n* = 150); *t*(295) = 10.93, *p* < .001, *d* = 1.27 (Levene *p* = .207, so Student's *t* is used) |
| A3 | Paired *t*-test, `prejudice_pre` vs `_post` | All participants: *t* ≈ 1.03, *p* = .31 (effects cancel). Contact only: *t*(149) = 3.07, *p* = .003 |
| A4 | One-way ANOVA: `cooperation_post` by `condition` | *F*(1, 290) = 24.2, *p* < .001, partial η² ≈ .08 |
| A4 | ANOVA: `age` by `gender` | null result: *F* = 0.24, *p* = .79 |
| A5 | ANCOVA: `prejudice_post` ~ `condition` + `prejudice_pre` | condition effect *F*(1, 297) ≈ 21.6, *p* < .001; pre-test *F* ≈ 199 |
| A6 | Repeated-measures ANOVA, Contact group only | *F*(2, 286) = 22.2, *p* < .001; Mauchly *W* = .86 (*p* < .001); GG ε = .87; means 3.96 → 3.78 → 4.13 (*N* = 144) |
| A7 | Hierarchical regression, DV `prejudice_post` | Block 1 (`prejudice_pre`) *R*² = .396; Block 2 adds `contact_quality_post`, `intergroup_anxiety_post`: *R*² = .563, Δ*R*² = .167; max VIF 1.30 |
| A8 | Mediation: `condition_code` → `contact_quality_post` → `prejudice_post` | *a* = 1.14, *b* = −0.36, *c* = −0.37, *c′* = 0.04 (*p* = .71); indirect ≈ −0.41, CI excludes 0 → full mediation |
| A9 | Moderation chart: `contact_quality_post` × `group_identification_pre` on `prejudice_post` | interaction ≈ −0.10, *p* = .012; steeper negative slope at high identification (−0.35 vs −0.18) |
| A9b | Correlation, pre-test variables | prejudice–anxiety *r* = .45; prejudice–contact quality *r* = −.31 |
| A10 | Latent profile analysis (4 post-test variables), *k* = 2 | two classes of about 47% and 53% |
| A10 | Growth curve: three prejudice waves | prejudice declines then rebounds (no fit indices are reported for growth models) |

(Values may differ in the last decimal depending on rounding settings and bootstrap randomness.)

## 2. `survey_example.csv` — Psychometric Survey (N = 250)

### 2.1 The story

A (fictional) questionnaire study measures four constructs on **five-point Likert scales** (1 = strongly disagree … 5 = strongly agree) with 15 items. The constructs are correlated as in theory: more intergroup contact goes with less prejudice and more wellbeing.

### 2.2 Variables

| Variable | Values | Meaning |
|---|---|---|
| `participant_id` | 1–250 | Participant number (do not analyse) |
| `age` | 18–65 | Age in years |
| `gender` | Female (~57%), Male (~40%), Non-binary (~3%) | Self-reported gender |
| `education` | High school, Bachelor's, Master's or higher | Highest education |
| `si1` – `si5` | 1–5 | **Social Identity** (5 items). **`si5` is reverse-worded**: reverse-score it before computing a scale score, reliability or fitting a model |
| `ic1` – `ic4` | 1–5 | **Intergroup Contact** (4 items) |
| `pr1` – `pr3` | 1–5 | **Prejudice** (3 items; higher = more prejudice) |
| `wb1` – `wb3` | 1–5 | **Wellbeing** (3 items) |

### 2.3 Missing data

About 1.2% of item responses are missing completely at random. That sounds small, but with 15 items it means that **43 of the 250 participants (17%)** have at least one missing item, so listwise deletion leaves **207** participants. This is a good dataset for comparing listwise deletion with FIML in CFA/SEM.

### 2.4 Built-in structure and answer key

| Tutorial | Analysis | What you should find |
|---|---|---|
| B1 | Reverse-score `si5` (Min 1, Max 5) | needed before every scale-level analysis |
| B2 | Cronbach's α | SI ≈ .75 (only ≈ .40 if `si5` is *not* reversed); IC ≈ .80; PR ≈ .74; WB ≈ .67 |
| B3 | EFA (15 items, `si5` reversed) | KMO = .77; Bartlett significant; four eigenvalues > 1 (3.48, 2.56, 1.57, 1.31); four-factor oblique solution matching the scales |
| B4 | CFA, four correlated factors (listwise, *N* = 207) | χ²(84) = 84.04, *p* = .48; CFI = TLI = 1.00; RMSEA = .002; SRMR = .043. A one-factor model fits badly (CFI ≈ .49) |
| B5 | SEM `PR ~ IC + SI`, `WB ~ IC + PR` | β(IC→PR) ≈ −.49; β(SI→PR) ≈ .25; β(IC→WB) ≈ .24; β(PR→WB) ≈ −.21 (*p* ≈ .05) |
| B6 | Network (EBICglasso, Spearman, 15 items) | about 31 of 105 possible edges; **4 communities** (Q ≈ .64) matching the four scales |
| B7 | Bayesian correlation of scale means | `SI_mean`–`WB_mean`: *r* ≈ .05, BF₀₁ ≈ 9.4 (evidence for the null); `IC_mean`–`PR_mean`: *r* ≈ −.33, BF₁₀ > 100,000 |

> The CFA fits almost perfectly because the data were simulated from exactly this model. With real data, expect imperfect fit and use modification indices cautiously.

## 3. `cvi_expert_ratings_example.csv` — Content Validity (12 items × 6 experts)

One row per item (`item`, "Item 01"–"Item 12"), one column per expert (`expert1`–`expert6`). Each cell is a relevance rating on the usual **4-point scale** (1 = not relevant, 2 = somewhat relevant, 3 = quite relevant, 4 = highly relevant).

In **Item Analysis & CVI**, select the six expert columns and set the threshold to **2.5** (ratings of 3 and 4 count as relevant).

| What you should find | |
|---|---|
| I-CVI | Items 1–6, 8, 9: 1.00 · Item 7: .83 · Item 10: .33 · Item 11: .50 · Item 12: .33 |
| S-CVI/Ave | .83 |
| S-CVI/UA | .67 |

Items 10–12 fall below the benchmark of .78 (Lynn, 1986, for six or more experts) and should be revised or dropped.

## 4. `timeseries_example.csv` — Monthly Counselling Visits (60 months)

| Variable | Meaning |
|---|---|
| `month` | Calendar month, `YYYY-MM`, January 2020 – December 2024 |
| `counselling_visits` | Number of visits to a (fictional) university counselling centre that month (102–182) |

The series has an upward trend and a yearly seasonal cycle. In **Forecasting**, choose *Exponential Smoothing*, Time = `month`, Target = `counselling_visits`. The model is Holt's linear trend (**no seasonal component**), so the forecast follows the trend but not the seasonal peaks: a useful lesson about checking forecasts against the data.

## 5. Suggested exercises

1. **Missing data.** Fit the same CFA with listwise deletion and with FIML on the survey data. How does *N* change? Which fit indices are available?
2. **Robust estimation.** Fit the CFA with **ML** and with **MLR**. How do the standard errors and the χ² change? (The survey items are ordinal with moderate skew, so differences are small. Robust methods matter most when data are strongly skewed or heavy-tailed.)
3. **Raw versus standardised.** Fit the CFA with *Raw data* and compare the unstandardised loadings with the Std.all loadings.
4. **A hidden effect.** Why does the paired *t*-test on all participants hide the effect of contact (A3)? What design feature of the experiment lets you interpret the group difference causally?
5. **Prior sensitivity.** Run the Bayesian *t*-test for A2 with a Cauchy scale of 0.5, 0.707 and 1.0. Does the conclusion change? Does it change for a *null* effect (e.g. `age` by `condition`)?
6. **Network.** Do the communities in the survey network match the four scales? Define the four scales as subscales and compare.
7. **Reporting.** Write the Results paragraph for A8 (mediation) in APA style, using the output of PsyStat.

---

## 6. Using your own data in the same way

Replace the example file with your own: one row per participant, variable names in the first row, no merged cells, and empty cells for missing values. Reverse-score negatively worded items before analysis, code groups as text labels or 0/1, and keep identifying information out of the file.

## 7. Regenerating the datasets

```bash
python tools/generate_examples.py
```

writes the four CSV files into `examples/` using fixed random seeds, so you always get identical data.
